# osu-paint v0.1.1

把 osu!mania 的音符当作像素，用手绘、文本或本地视频制作图案与动画，导出谱面和配套皮肤。

本版整理了下载与使用文档，并首次在 Release 提供 Linux x64 试用包。Windows、Linux 均无需安装 Python，下载无需登录 GitHub。

## 开始使用

1. 运行应用，选择 `lazer` / `stable`，绘图、打开示例或导入视频；按需导入音频。
2. 设置展示时间和与游戏一致的滚速，预览并保存 JSON 项目。
3. 导出 `.osz`，将谱面与导出目录里匹配客户端、窗口比例的 `.osk` 分别导入游戏。
4. 选择配套皮肤，使用向下滚动、相同滚速和 **No Fail**。不要用 Autoplay 观看。

[完整使用指南](https://github.com/YeLn10/osu-paint/blob/v0.1.1/docs/usage.md) · [反馈问题](https://github.com/YeLn10/osu-paint/issues/new/choose)

## 已知限制

- 预览模拟连续位置，不能保证实机零残影。Autoplay 曾收到强烈频闪反馈；lazer“音乐继续、画面定格”仍无经过实机确认的完整解决方案。
- 目标 lazer `2026.921.0` 在 >10K 强制双舞台，11/13/15/17K 少一列；stable 低键数可能无法横向铺满。
- 皮肤须匹配客户端、窗口比例和画布行数。
- Linux 已有 CI 测试、构建与虚拟显示器启动检查，其他发行版及实机游戏组合仍需试用反馈；不支持此包用于 ARM64 或 Alpine/musl。
- Windows EXE 未进行代码签名；请从本仓库下载并比对 `SHA256SUMS.txt`。

osu-paint 是独立工具，非 osu! 官方项目。项目代码与生成皮肤采用 MIT 许可，桌面包内的第三方组件遵循各自许可证，详见包内 `THIRD_PARTY_NOTICES.md`。
