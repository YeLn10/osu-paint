# osu-paint v0.1.0

首次公开发布：用手绘、文本或视频创建 osu!lazer / stable 的像素图案与动画谱面。

## 下载与使用

1. 下载 `osu-paint-v0.1.0-windows-x64.zip`，解压后运行 `osu-paint.exe`。适用于 Windows 10/11 x64，无需安装 Python。
2. 选择客户端，绘图或导入视频；可独立导入音频并调整倍速、截取起点与谱面开始位置。
3. 导出 `.osz` 后，同时导入导出目录里匹配客户端与窗口比例的 `.osk`。
4. 游戏中使用相同滚速、向下滚动和 No Fail。

## 本版内容

- 1–18K 共用编辑器、连续位置预览、JSON 项目保存与 `.osz` 导出。
- 手绘与视频均允许空白帧，保留其时间，不插入假音符。
- 独立音频导入，0.25–4 倍速并保持音高，预览和导出同步应用；JSON v3 保存原轨。
- 视频导入前可填写滚速，支持 FPS、刷新率、尺寸及黑白转换调整。
- 自由模式自动清场，按实际需要检查间隔；均分模式保留手动控制。
- 连续亮格合并长条，两客户端各五种比例 Pixel Film 皮肤。
- MIT 项目许可证、完整构建教程、自动测试和标签发布工作流。

## 已知限制

- 预览只模拟位置，刷新率排帧不能保证实机零残影。
- 目标 lazer `2026.921.0` 在 >10K 强制双舞台，11/13/15/17K 少一列；皮肤无法解除。
- stable 低键数可能无法横向铺满。
- 独立皮肤包默认 24 行；画布行数不同，请使用应用导出时生成的皮肤。
- EXE 未进行代码签名；下载后可用 `SHA256SUMS.txt` 校验。

旧 JSON v1/v2 可继续打开；调整音轨后保存为 v3，旧版程序不能打开 v3。建议更新前保留项目备份。

源代码和构建教程均随仓库公开；发布包内的第三方组件遵循各自许可证，详情见 `THIRD_PARTY_NOTICES.md`。
