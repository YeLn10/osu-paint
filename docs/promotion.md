# 中文宣传文案

## 标题

osu-paint：把 osu!mania 的音符当作像素，画画、做动画

## 可直接发布的介绍

做了一个小工具 **osu-paint**：可以手绘、粘贴文本图案，或把本地视频转换成 osu!mania 的黑白像素动画。支持 osu!lazer / stable，能逐帧调整时间、添加独立音频，导出 `.osz` 谱面和匹配画布的皮肤，无需 osu! 插件。

目前已提供 Windows x64 版和 Linux x64 试用包，下载、解压即可使用，无需安装 Python。项目代码和生成皮肤采用 MIT 许可，欢迎试用、反馈或参与改进。

观看时请使用本次导出的皮肤、相同滚速、向下滚动和 No Fail。预览不等同于实机效果，切帧仍可能有残影；不要用 Autoplay 观看，客户端与高键数限制请看使用指南。

- 项目与界面截图：https://github.com/YeLn10/osu-paint
- 最新下载：https://github.com/YeLn10/osu-paint/releases/latest
- 使用指南：https://github.com/YeLn10/osu-paint/blob/main/docs/usage.md
- 问题反馈：https://github.com/YeLn10/osu-paint/issues/new/choose

## 群聊短版

做了个 osu!mania 像素动画工具 osu-paint，可以手绘、导入文本或本地视频，导出谱面和配套皮肤。支持 lazer / stable，Windows 版和 Linux 试用包已开放下载，无需 Python。观看请开 No Fail、勿用 Autoplay；实机切帧仍可能有残影。下载：https://github.com/YeLn10/osu-paint/releases/latest

## 演示素材

可使用仓库的 [编辑器截图](desktop.png) 和 [爱心示例](../examples/heart.txt)，无需附带个人媒体。

短视频建议依次展示：画出图案或打开示例 → 预览 → 导出谱面与皮肤 → 游戏内播放。编辑器画面标注“预览”，游戏画面标明客户端版本、滚速、窗口比例和刷新率；实机片段需实际录制，当前仓库截图不能作为实机效果证据。
