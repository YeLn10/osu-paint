# 统一客户端与切帧优化验证

日期：2026-10-06。目标：一个编辑/导入/导出入口，保留 stable 和 lazer 各自的时间规则，再减少正常播放的过渡窗口。原相邻 stable 仓库、EXE 和用户媒体/项目不改动。

## 合并基线

合并提交 `6ddcc1e` 前后，两端各 7 个合成案例的完整 `.osu` SHA-256 一致，覆盖均分、手动时长、长条/空档、重复图案、空白、低滚速和小数窗口。统一项目读写 `target_client`，未标记默认 lazer；目标变化撤销刷新对齐，但不改帧和音轨。161 项测试通过，根目录两端各五个皮肤可重建且互不覆盖，统一 EXE 构建成功。

## stable：按实际头尾端点安排整数槽

旧算法给每行都留一个整数毫秒，即使那行没有任何短音符或长条端点。24 行整列长条因此仍用 25 ms。新算法只给不同头尾所在行分配整数槽，保留原空间距离；N 个端点行加一个清场槽共 N+1 ms。独立进场没有需要判定的端点，可用 1 ms。长条不能跨空格，空行不因时间压缩被填黑。

排帧仍保留 H+1 ms 最坏预算，不移动已有窗口或音轨，不借此擅自提高导入 FPS。共用切帧在原下一幅开始时结束，多余时长用于静置。全行短音符仍需 H+1 ms；关闭极速仍使用原手动时长。

## lazer：限制长静态组对全片参考速度的影响

旧算法先以保守参考速度复用重复帧，再由最长有内容组限制全片参考 beatLength。少数静态段会拖慢其余动态段。

首次优化保留原策略作基线，仅试一个按 4900 ms 参考预算分组的候选；后续的温和候选见文末。候选仍检查整个复用跨度（含延长静置）不超过半内部像素，并保留约 1 内部像素的判定余量。只有内部总切帧窗口减少至少 20%、画面组数与音符数分别增加不超过 10% 时采用。首尾进退场不计入收益，所以纯静态序列不会为了缩短首尾而重绘。未满足条件、非极速以及长单帧无法拆分时保留基线。

这里的负载上限是保守的生成器约束，不是客户端性能保证。额外重绘也可能改变闪屏出现的时刻，仍需实机比较。

合成输入：24 行两列，60 帧相同画面后接 120 帧左右交替图案，20 FPS；两端分别使用自己的保守排帧预算。总窗口是所有进出场区间的并集长度，包含首尾，不是 GPU 检测到的闪屏次数。

## 回归与边界

`test_transition_optimization.py` 先在旧实现上失败，再覆盖端点槽压缩、实际序列化头尾几何、未来判定时间、空档/黑场、不同密度切帧、纯静态不重绘、非极速不变，以及拒绝让稠密静态音符从 552 个膨胀到 4008 个的候选。lazer 检查分段 float32 距离；stable 使用独立 double 积分及绿线 float32 规则，不混用两端 helper。原刷新相位反例继续保留。

本次是模型、序列化、UI/媒体回归和打包验收，**没有 GPU 实机零闪屏结论**，也没有修改游戏 DLL/配置。Auto 强烈频闪、lazer 音乐继续但画面定格不因此被证明解决；观看仍用 NF，不开 Auto。后者的客户端时钟诊断见 [定格记录](lazer-clock-freeze.md)。

过程日志和前后数值保存在被忽略的 `build/merge-diagnostics/`，不是运行依赖，也不提交媒体或反编译内容。

最终验收：完整 169 项回归通过；按 `build_desktop.ps1` 重建 EXE，核对五个包内模块与源码一致、内置 FFmpeg 存在，并执行包内桌面类和两端编译/导出，逐字节复现十套交付皮肤。只读旧导出的 146713 个序列化头尾端点均保持在切帧前的未来，最大几何误差为约 `8.13e-9` 舞台高度，最长完整复用组漂移在 768 px 高舞台上约为 0.4735 px；6575 帧原时间窗口不变。该漂移不是实机采样误差。

## 2026-10-06 后续：避免激进候选失败后完全回退

复现：24 行两列，60 帧相同画面后接 20 帧左右交替图案，20 FPS。旧策略的 4900 ms 候选增加超过 10% 的画面组，被负载保护拒绝，于是全部动画仍使用约 0.4901 ms 清场。

保持 4900 ms 上限、半内部像素漂移预算、20% 最低过渡收益以及 10% 组数/音符增量限制不变，额外比较一个“原参考两倍、不超过 4900 ms”的候选。两个候选均对原计划检查限制，不能逐次放宽负载。只改变音符复用，保存的帧起止、空白和音轨时间不变。

上述长条样例：参考 beatLength 624.363 → 1292.351 ms，单次清场 0.490100 → 0.236778 ms，总切帧窗口 10.782189 → 5.682667 ms（约减少 47.3%），音符/画面组 21 → 23。短音符使用相同几何规则，仍受同一负载限制。回归先在旧实现失败，再验证实际序列化积分、头尾未来判定时间、完整复用跨度漂移及帧窗口不变。
