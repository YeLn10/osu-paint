# 使用指南

[项目首页](../README.md) · [皮肤说明](skin.md) · [源码运行与构建](building.md)

## 绘制与保存

Windows 发布包解压后运行 `osu-paint.exe`。从源码构建的程序位于 `dist/osu-paint.exe`，也可通过 `osu-paint.pyw` 或 `osu_paint_desktop.py` 启动，环境准备见构建指南。

左侧是画布、帧列表与音轨，右侧是预览与时间参数。手绘项目在顶部选择 `lazer` / `stable`；视频项目在导入窗口选择目标，导入后换端需重新导入。

- **绘图**：新建时设置 1–18 列和行数，左键点按或拖动绘制，右键擦除。“编辑文本”可粘贴 `#` / `.` 图案，取消或 Esc 不应用修改。
- **帧列表**：新增空白帧、复制、删除或切换。手绘与视频都允许 0 亮格空白帧，保留时间；整段至少有一个亮格才能导出谱面，全空白草稿仍可保存。
- **合并长条**：默认开启，仅合并同一帧、同一列的连续亮格，不跨空格。旧项目按保存的开关恢复，缺少开关时使用短音符。
- **JSON**：保存图案、逐帧时间、参数和音轨，是继续编辑或迁移项目的格式。TXT 只保存图案，不保留时间、音轨和设置；另存 TXT 不会清除尚未保存的项目参数状态。

新建、打开或关闭前会确认未保存修改。新增或复制帧不会自动挪动其他帧的时间。`report.json` 是导出报告，不能作为项目打开。

## 展示时间与清场

“开始 / 结束”指完整图案的展示区间：进场发生在开始之前，退场不早于结束。每帧须结束晚于开始，按列表顺序排列，有限速度的滚动无法设为零时间瞬移。

| 设置 | 用法 |
| --- | --- |
| 均分模式 | 各帧平分总时间，先扣除切帧所需时长。极速清场默认开启；关闭后可手动填写切帧时长。 |
| 自由模式 | 逐帧填写起止时间，始终自动清场，按各空档与实际清场需求校验；显示最短空档和最大实际清场时长。 |
| 游戏滚速 | 须与游戏一致；stable 为 1–40 的整数，lazer 可用小数。它影响位置与清场速度，不是动画 FPS，也不会移动自由模式的展示时间。 |
| 极速清场 | 根据内容和客户端优化实际推进时间。短间隔共用推进，余量延长静置；相同画面在条件允许时复用音符，主动空场保留。 |

切换模式会保留原手动时长，供切回均分模式使用。自由模式保持填写的帧时间与音轨；如果清场放不进空档，需要扩大间隔或调整滚速。`examples/free.json` 提供三帧自由时间表示例。

**极速为什么比手动下限更短？** lazer 会优化参考 BPM 与实际亮格行程；stable 只给用到的短音符或长条头尾行安排整数时刻。例如 24 行整列长条在 stable 极速模式可用 3 ms，手动整屏模型需 25 ms。直接把极速结果填入手动模式并不等价，算法见 [时间模型](timing.md)。

## 独立音频与音轨设置

点击“导入音频”，选择 MP3、WAV、Ogg、FLAC、M4A 等文件，再设置：

| 参数 | 含义 |
| --- | --- |
| 倍速 | 0.25–4 倍，保持音高。 |
| 谱面开始时间 | 处理后的音乐从谱面第几毫秒开始播放。 |
| 原音频截取起点 | 跳过原音频开头的多少毫秒。 |

例如截取起点 1000 ms、倍速 2、谱面开始 2000 ms，表示跳过原曲第一秒，将剩余音乐以两倍速度从谱面第 2 秒开始播放。

点击“应用音轨”后用于预览与导出；画布下方“音轨设置”可继续调整或移除，视频提取的音轨也适用。每次调整都从保存的原轨生成，取消、失败和未应用的设置保留原音轨。音轨编辑不会移动画面时间。

独立或已调整音轨的 JSON v3 同时保存原轨与最终音轨，再次编辑无需原文件。旧 JSON v1/v2 仍可打开；未调整的视频项目保持 v2。旧版程序不能打开 v3，升级前可保留项目备份。

## 视频导入

1. 点击“导入视频”，选择本地视频。实际格式支持取决于内置 FFmpeg 解码器。
2. 选择目标客户端，设置 FPS、列数和行数。默认 10 FPS、10 列；lazer 默认 24 行，stable 默认 12 行。切换目标仅调整尚未手动编辑的默认行数。
3. 设置“音画开始 / ms”，默认 2000。它是谱面中的共同起点，不是源视频的裁剪起点。
4. 调整黑白转换参数，选择“预览帧”并点击“刷新预览”，对照原画面与结果。序号从 1 开始，10 FPS 的第 11 帧对应源视频 1000 ms；选帧只影响预览，完整导入仍从开头开始。
5. 填写与游戏相同的滚速、屏幕刷新率，按需启用长条，然后开始导入。完成后可逐帧编辑、保存 JSON 或导出。

预览和转换在后台执行，可取消；失败或取消保留原项目及客户端。导入后自动使用自由模式和极速清场。降低滚速保留原帧时间，若清场已放不进空档，可扩大空档或按新滚速重新导入。

### 画面参数

分辨率指音符画布的列数 × 行数，不是源视频编码尺寸。视频会变成黑白音符，不作为背景视频附加，也不保留彩色。

| 参数 | 范围与作用 |
| --- | --- |
| FPS | `0 < FPS ≤ 60`，支持 `12.5`、`29.97` 等小数；不会向上提高请求帧率。 |
| 画布 | 1–18 列、1–128 行。较低列数会丢失细节；客户端限制见皮肤说明。 |
| 黑白阈值 | 0–255，默认 128；灰度达到阈值的像素生成黑色音符。 |
| 亮度 | -255–255，默认 0。 |
| 对比度 | 大于 0 且不超过 5，默认 1；缩小后、阈值判断前应用。 |
| 亮暗反转 | 改为暗部生成音符，也会反转缩放时补的黑边。 |
| 缩放 | 拉伸填满（默认）、等比留边或居中裁剪。 |

每次最多 20,000 帧，总采样像素不超过 2,000,000（帧数 × 列数 × 行数），超限会拒绝而非截断。滚速过低、采样周期容不下展示与清场时，应降低 FPS。提高 FPS 不会补出源视频中不存在的细节，并会增加音符数、导出大小和游戏负担。

### 同步与刷新率

填写游戏实际使用的屏幕 Hz，支持 `60`、`120`、`165`、`59.94`、`60000/1001` 等。默认 60 是初值，程序不会检测显示器，游戏 FPS 也不能代替屏幕 Hz。程序根据刷新率与开始时间自动排帧，无需手动调相位。

视频按时间戳采样，支持可变帧率。黑场保留时长；尾帧按解码器提供或推断的时长对齐到完整采样周期，时长信息不足时可能有估计误差。首个音轨转为 Ogg，保留源音画相对延迟；无音轨时使用静音并提示，音轨转换失败则整次导入失败。

帧时间调整不会移动音轨。改变滚速、帧时间、时间模式或画布尺寸会撤销失效的刷新对齐标记。要按新的 FPS、画布、共同起点或排帧策略生成，请重新选择原视频导入；直接导出旧 JSON 会保留原帧时间。项目只记录原文件名，不记录个人媒体的绝对路径。

Hz 只能确定刷新间隔，不能确定实际显示相位。自动排帧可减少某些固定相位连续采到过渡的次数，仍不能保证实机零残影；算法与反例见 [时间模型](timing.md) 和 [研究索引](research/README.md)。

## 预览、导出与游戏设置

桌面预览支持播放、暂停、拖动时间轴和定位当前帧。有音轨时画面跟随音频进度，音轨结束后画面继续无声播放。拖动或定位会暂停；编辑、换项目或关闭会停止音乐。音频设备不可用时提示错误并继续画面预览。HTML 预览无声，两种预览都只模拟连续位置。

点击“导出 .osz”时会保存计划与音轨快照，后台导出期间可以继续编辑；同名文件覆盖前确认。

| 输出 | 用途 |
| --- | --- |
| `pattern.osz` | mania 谱面与音频，拖入目标游戏导入。 |
| `pixel-film*.osk` | 所选客户端的五种比例皮肤，匹配本次画布行数，需单独导入并选择。 |
| `pattern.osu`、音频文件 | 未压缩谱面及音频。 |
| `preview.html` | 浏览器位置预览。 |
| `report.json` | 帧时间、音符位置、参考 BPM 与漂移报告。 |
| `播放设置.txt` | 使用刷新率自动排帧时附带的播放说明。 |

游戏中选择 `SV Pattern` 难度，使用对应皮肤、向下滚动、默认舞台缩放、相同滚速与 No Fail；不要跳过开头，避免恒速滚动、改列数、随机排列、镜像和速度类 MOD。不要用 Autoplay 观看，Cinema 会隐藏音符区域。比例、高键数和 stable 底边遮挡说明见 [皮肤说明](skin.md)。

## 命令行

文字编译仅需 Python 3.10+ 标准库；视频需安装 `requirements.txt`。以下命令在仓库根目录运行，环境准备见 [构建指南](building.md)。

```powershell
python osu_paint.py examples/heart.txt --start-ms 2000 --end-ms 4000 --fast-clear --output output/heart
python osu_paint.py examples/pulse.txt --client stable --start-ms 2000 --end-ms 5000 --fast-clear --merge-holds --output output/pulse
python osu_paint.py "D:\Videos\clip.mp4" --video --refresh-hz 60000/1001 --fps 10 --width 9 --height 24 --start-ms 2000 --scroll-speed 27 --merge-holds --output output/video
python osu_paint.py --help
```

文本每行等宽，`#` 为亮格、`.` 为空位；多帧用独立的 `---` 行分隔，同尺寸各帧平分总时长。CLI 文本模式保留严格校验，每帧至少一个 `#`；桌面文本导入允许空白帧。

```text
#..
.#.
..#
---
..#
.#.
#..
```

- `--client lazer` 为默认，`--client stable` 选择另一客户端；滚速须与目标游戏一致。
- 文字模式默认手动切帧 12 ms；`--fast-clear` 启用极速，`--transition-ms` 修改手动时长，`--merge-holds` 启用长条。
- 视频自动极速清场，不传 `--end-ms`；结束时间由采样结果决定。可用 `--threshold 100 --brightness 10 --contrast 1.2 --invert --fit contain` 调整画面，未填写刷新率时按 60 Hz 排帧。
- 同一命令再次运行会覆盖同名生成文件。

手动 12 ms 的单帧示例若展示区间为 2000–4000 ms，则 1988–2000 ms 进场、2000–4000 ms 展示、4000–4012 ms 退场。多帧先扣除内部过渡时间，实际各帧窗口见 `report.json`。音符的判定时间通常位于退场段，这是反解位置的结果。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 0 亮格不能导出 | 可以保存空白草稿；导出要求整段至少一个亮格，CLI 文本另有逐帧严格校验。 |
| 降低滚速失败 | 检查实际清场与最短空档；扩大间隔，或按新滚速重新导入视频。 |
| 画面比例、行高或底边不对 | 重新导出并同时导入新 `.osz` 与匹配客户端、比例、行数的 `.osk`，覆盖同名皮肤后重新载入。 |
| 更新后仍沿用旧排帧 | 新排帧需要重新导入视频；仅重新导出用于应用编译器或皮肤修复。 |
| lazer 音乐继续、画面定格 | 目标 `2026.921.0` 已复现客户端 500 ms 时差保护；当前无同时解决定格与频闪的实机确认方案，勿盲目改 SV。详见 [诊断记录](research/lazer-clock-freeze.md)。 |
| EXE 或依赖问题 | 见 [构建指南的常见问题](building.md#常见问题)。 |
